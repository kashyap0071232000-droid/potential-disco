# Medical & Dental College Counselling Intelligence Platform

A comprehensive Progressive Web App (PWA) for medical and dental college counselling data in India.

## Features

### 🏥 College Information
- Complete database of all medical and dental colleges in India
- Course offerings and seat distribution per branch
- Detailed college profiles and contact information

### 📊 Counselling Data Analysis
- AIQ and Karnataka counselling data (2023-2024)
- UG, PG, BDS, and MDS counselling rounds
- Side-by-side comparison of Round 1 and Round 2 data
- Advanced filtering and search capabilities

### 🔧 Advanced Admin Suite
- Excel to JSON data processing unit
- Data verification and validation system
- Automated data push to production
- Advanced analytics dashboard

### 📱 PWA Features
- Offline functionality
- Mobile-responsive design
- Fast loading and caching
- Cloudflare + GitHub hosting ready

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- Service Workers for offline functionality
- IndexedDB for local data storage
- Chart.js for data visualization
- Bootstrap 5 for responsive design

## Deployment
- Static site optimized for Cloudflare Pages
- GitHub Actions for CI/CD
- JSON-based database for easy updates
